Amader Bank Management System 

    A comprehensive console-based banking application written in C. This project simulates a fully-featured banking system including account management, mobile banking, DPS, FDR, loans,        bill payments, and secure fund transfers.

Features

    Account Management: Register new accounts, switch profiles securely with password protection, and update personal settings (password, email, phone, address).

    Transactions: Deposit cash, withdraw funds, and transfer money between accounts or from debit to credit cards.

    DPS (Deposit Pension Scheme): Set custom durations and monthly installments to calculate and track maturity amounts.

    FDR (Fixed Deposit Receipt): Create fixed deposits with fixed interest rates and check maturity details.

    Loan Section: Apply for loans, manage repayments, and track outstanding dues.

    Bill Payments: Pay utility bills (Electricity, Gas, Water, Internet) using Debit or Credit cards and view transaction history.

    Mobile Banking: Transfer funds between your main bank account and a mobile wallet, or send money to other mobile numbers.

Requirements

    Because this program uses libraries like <conio.h> and Windows-specific system calls (system("cls")), it is best run on a Windows environment using an IDE like Code::Blocks, Dev-C++, or Visual Studio.

    Compiler: GCC or any standard C compiler supporting C99.

To Getting Started

    Clone or Download the source code (BANK PROJECT_MAIN_Group_01.c) to your local machine.

    Open your C IDE (e.g., Code::Blocks or Dev-C++).

    Compile and Run the source file.

Navigation Guide

    Upon launching the application, you will be prompted to register your first account. Once registered, you will access the Main Dashboard with the following options:

    ? – Switch / Select Profile

    0 – Open New Account

    1 – DPS Menu

    2 – FDR Menu

    3 – Transactions (Deposit / Withdraw / Transfer)

    4 – Debit to Credit Transfer

    5 – Loan Services

    6 – Bill Payments & History

    7 – Account Settings

    8 – Current Account Status & Balances

    9 – Mobile Banking

    X – Exit Program
